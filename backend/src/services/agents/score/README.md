# AG-05 · Explicación de RemateScore

El servicio calcula el desglose en Express. La versión `propuesta-0.1` usa únicamente el peso económico que puede comparar con los datos actuales. Uso y ubicación, atributos específicos y completitud quedan pendientes porque el perfil y las fichas aún no contienen evidencia estructurada suficiente.

Mientras falte un componente, la respuesta usa `status: "not_evaluable"` y `score: null`. Los pesos y la versión son una propuesta del anteproyecto, no una regla de afinidad validada. El proveedor solo puede explicar los valores calculados y no recibe nombre, correo ni comentarios.
